# Задание 0.7.5 — цветовые схемы и цвета (от Claude, чат планирования)

14 цветовых схем (7 светлых, 7 тёмных), 12 цветов для целей, свой цвет у задачи, настройка «Цвета схемы применять» (только экраны / ко всему: логотип, живая заставка, иконка на рабочем столе).
Выполняется после выпуска 0.7.4. Требования и «Готово, если…» — в CLAUDE.md. Новые пакеты — только после «да» пользователя.

Остановки (ждать ответа): шаг 2 (сверка), шаг 4 (только если нужен эскиз, которого нет), шаг 7 (проверка на телефоне), перед push и публикацией релиза.

Файлы пакета:
- `themes.json` — **единственный источник цветов**: токены всех 14 схем, цвета знака по схемам, 12 цветов целей (светлый/тёмный вариант), миграция старых цветов, значения по умолчанию. Контраст уже проверен.
- `icons/` — 13 наборов иконки рабочего стола (WebP): `ic_scheme_<key>_fg.webp` 432×432 (передний слой адаптивной иконки, прозрачный) и `ic_scheme_<key>_legacy.webp` 192×192 (для Android 7). Для «Белой» — фирменная иконка (уже в проекте). Белый силуэт для тематических иконок — общий, уже есть (`adaptive-icon-monochrome.png`).
- `sketches/` — утверждённые эскизы 31–34.

## Шаг 3. Что делаем

### 3.1 Движок схем
- `src/theme/`: схемы из `themes.json`, хук `useTheme()` отдаёт токены активной схемы. Ключи токенов у всех схем одинаковые (bg, card, cardBorder, cardStrong, track, text, textMuted, primary, onPrimary, primaryStrong, warn, outline). Остальные существующие токены (reward и т.п.) — как сейчас.
- Настройки: `themeMode` (system / light / dark — уже есть), `lightScheme` (по умолчанию `white`), `darkScheme` (по умолчанию `night`), `applyScope` (`screens` по умолчанию / `all`).
- Активная схема: режим светлый → `lightScheme`, тёмный → `darkScheme`, «как в системе» → по теме телефона. Переключение мгновенно, без перезапуска.
- «Белая» теперь совсем белая (фон #FFFFFF, карточки #F6F6F9 с рамкой) — у пользователей светлой темы вид изменится, это утверждено.
- Проверить, что ни один экран не использует цвета мимо `useTheme()` (поиск hex в `app/` и `src/components/`).

### 3.2 Цвета целей и задач (эскиз 33)
- 12 цветов из `themes.json → goalColors`: в светлых схемах — `light`, в тёмных — `dark`.
- Миграция БД: `goals.color` старые ключи → новые по `goalColorMigration` (mint→teal, остальные одноимённые, неизвестное → blue). Новая колонка `tasks.color TEXT NULL` (NULL = «как у цели»). Миграции — с тестами на sql.js, данные не теряются.
- Выбор цвета — панель снизу: 12 кружков (6×2) с подписями, выбранный — с галочкой и обводкой. В форме задачи первым пунктом «Как у цели».
- Цвет задачи: полоска слева у строки задачи и рамка/заливка чекбокса (в календаре тоже). Цвет цели — полоса прогресса и метка, как сейчас.

### 3.3 Экран «Тема и цвета» (эскиз 32)
- Режим: Светлая / Тёмная / Как в системе.
- «Светлая схема» и «Тёмная схема» — сетки миниатюр (рисуются из токенов, не картинками), выбранная — обводка и галочка, подписи ru/kk/en из `themes.json`.
- «Цвета схемы применять»: «Только к экранам приложения» (подпись: «Логотип, заставка и иконка — фирменные, ультрамарин») / «Ко всему» (подпись: «Экраны, логотип, заставка и иконка на рабочем столе — в цвет схемы»).
- Подсказка под режимом «Как в системе»: «светлая или тёмная — как настроено в телефоне».

### 3.4 Логотип и живая заставка по схеме (эскиз 34)
- `LogoMark` берёт цвета: при `applyScope = all` — `schemes[active].mark` и фон `tokens.bg`; при `screens` — `brandMark.light` / `brandMark.dark` по режиму телефона (светлый: белый фон, тёмно-синий флагшток; тёмный: фон «Ночь», синий флагшток).
- Живая заставка та же (анимация из 0.7.4), меняются только цвета. Подписи («Чекпоинт», слоган, «Прототип») — цветами схемы (`text`, `textMuted`, `warn`).
- Нативная заставка (первые доли секунды, менять на ходу нельзя): `splash-blank.png`, фон #FFFFFF в светлом режиме телефона и #1B1740 в тёмном (`expo-splash-screen`, настройка `dark`).
- Никаких видео/GIF-файлов в приложении: всё рисуется кодом.

### 3.5 Иконка на рабочем столе по схеме (только при `applyScope = all`)
- 13 `activity-alias` (по одному на схему, кроме «Белой») + основной (фирменная иконка). Через config plugin `plugins/withSchemeIcons.js`: ресурсы адаптивных иконок (`mipmap-anydpi-v26/ic_scheme_<key>.xml`: фон — цвет `iconBackground` схемы из `themes.json`, передний слой — `ic_scheme_<key>_fg`, монохромный — общий), legacy — `ic_scheme_<key>_legacy`. Всё генерируется при `prebuild`, без ручных правок `android/`.
- Маленький локальный нативный модуль (Kotlin) `setLauncherIcon(key | 'default')`: включает нужный alias, выключает остальные (`DONT_KILL_APP`). Новых пакетов не ставить.
- Какая иконка: «Как в системе» → по `lightScheme`; «Светлая» → `lightScheme`; «Тёмная» → `darkScheme`. «Белая» → фирменная. `applyScope = screens` → всегда фирменная.
- Смена иконки — только после подтверждения: диалог «Иконка на рабочем столе сменится. На некоторых телефонах приложение закроется, а ярлык придётся вернуть из меню приложений» — «Сменить» / «Не менять иконку» (тогда схема применяется ко всему, кроме иконки; отметить в настройках строкой «Иконка — фирменная»).
- Само переключение alias — когда приложение уходит в фон (не посреди работы).
- Логика выбора ключа иконки — `src/logic/` + тесты.

### 3.6 Тексты
- Названия схем и цветов ru/kk/en — из `themes.json`; kk — в `docs/i18n-review.md`. Новые подписи экранов — на трёх языках.

### 3.7 Тесты
- Все схемы имеют одинаковый набор токенов; у всех 12 цветов есть light/dark.
- Автотест контраста по `themes.json` (те же пороги, что в `note`), чтобы будущие правки цветов не ломали читаемость.
- Миграции: старые ключи цветов → новые; `tasks.color` добавлена, данные целы.
- Выбор активной схемы и ключа иконки для всех комбинаций режима и `applyScope`.
