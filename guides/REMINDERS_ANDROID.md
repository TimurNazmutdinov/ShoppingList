# Надёжные напоминания на Android (уроки «Чекпоинта»)

## Основа
- `expo-notifications`, только локальные уведомления. Канал Android «Напоминания».
- Разрешение (Android 13+) — не при первом запуске, а в контексте: при первом включении «напомнить» → панель «Напомнить о покупках?» → системный запрос. «Не сейчас» — больше не спрашивать автоматически.
- Запрещено в телефоне → на экране «Напоминания» плашка с кнопкой «Открыть настройки телефона».

## Расписание
- Логика — `src/logic/reminders.ts`, чистые функции + тесты.
- Группировка: одно уведомление на день («Сегодня купить: молоко, хлеб и ещё 3»), не по одному на товар.
- Время по умолчанию (например 10:00 для покупок), тихие часы 22:00–08:00 (попало внутрь — перенос на конец).
- Планировать только ближайшие 50 (лимит ОС); пересчёт при запуске, возврате в приложение, любом изменении данных и настроек, смене языка.

## Samsung и «спящие приложения» (главный урок)
- Симптом: уведомления приходят только после открытия приложения. Причины: режим сна приложений и неточные будильники.
- Делать сразу:
  - разрешение `SCHEDULE_EXACT_ALARM` и проверка, выдано ли (локальный нативный модуль, если нужно);
  - блок **«Состояние напоминаний»** на экране «Напоминания»: уведомления ✓/✗, точные будильники ✓/✗, без экономии батареи ✓/✗, запланировано N, ближайшее — дата/время; у каждого ✗ — кнопка в нужные системные настройки;
  - подсказка для Samsung: Настройки → Батарея → Ограничения в фоне → «Никогда не спящие приложения»;
  - пересчёт расписания после перезагрузки телефона.
- Проверка: напоминание через 2–3 минуты при закрытом приложении и после перезагрузки.
