# Новые казахские тексты 0.7.4 — на проверку носителем

Для каждой строки: верно или впишите, как правильно по-казахски. Пометки в фигурных скобках ({left}, {symbol}…) — место для числа или названия, их не меняйте.

| Ключ | По-русски | По-казахски (сейчас) | Как правильно |
|---|---|---|---|
| `theme.systemLight` | Светлая тема телефона | Телефонның жарық тақырыбы | |
| `theme.systemDark` | Тёмная тема телефона | Телефонның қараңғы тақырыбы | |
| `theme.badgeDay` | день | күн | |
| `theme.badgeNight` | ночь | түн | |
| `shortcut.add` | Добавить товар | Тауар қосу | |
| `shortcut.today` | Сегодня | Бүгін | |
| `shortcut.new` | Новый список | Жаңа тізім | |
| `lists.budgetLabel` | Бюджет, {symbol} · необязательно | Бюджет, {symbol} · міндетті емес | |
| `budget.totalLabel` | Итого | Барлығы | |
| `budget.of` | из {budget} | {budget} ішінен | |

## Заметки релиза 0.7.4 (страница релиза на GitHub)

| По-русски | По-казахски (сейчас) | Как правильно |
|---|---|---|
| «В магазин»: крупный режим покупок, экран не гаснет, нажатие на товар — куплено | «Дүкенге»: ірі өрнекті сатып алу режимі, экран өшпейді, тауарға басу — сатып алынды | |
| «Купить снова»: частые покупки одним касанием, в пустом списке и рядом «Часто:» над строкой ввода | «Қайта сатып алу»: жиі алатын тауарлар бір басумен, бос тізімде және енгізу жолының үстіндегі «Жиі:» қатарында | |
| Бюджет списка: «Итого из…», остаток или превышение, сумма и бюджет на карточке | Тізім бюджеті: «Барлығы … ішінен», қалдық немесе асып кету, карточкада сома мен бюджет | |
| Ярлыки на иконке: «Добавить товар», «Сегодня», «Новый список» | Белгішедегі жылдам әрекеттер: «Тауар қосу», «Бүгін», «Жаңа тізім» | |
| «Ночь» — голубые кнопки; «Как в системе» — свои профили для светлой и тёмной темы телефона | «Түн» — көгілдір түймелер; «Жүйедегідей» — телефонның жарық және қараңғы тақырыбына өз профильдеріңіз | |
| Быстрый ввод понимает числа словами («рис одна пачка 500 тенге»); экран обновления без списка изменений | Жылдам енгізу сандарды сөзбен түсінеді («күріш бір қап 500 теңге»); жаңарту экраны өзгерістер тізімінсіз | |
