4. Ярлыки на иконке приложения

Долгое нажатие на иконку ShoppingList на рабочем столе — меню из трёх действий. Любое можно перетащить на рабочий стол отдельной иконкой (так устроен Android).

Рабочий стол, долгое нажатие

Добавить товар
Сегодня
Новый список
ShoppingList
  • Добавить товар — открывается последний список, курсор сразу в строке ввода, клавиатура поднята.
  • Сегодня — вкладка «Сегодня». Новый список — окно создания списка.
  • Подписи на трёх языках, по языку приложения. Заставка при входе через ярлык не показывается. Без новых пакетов (настройка сборки).
