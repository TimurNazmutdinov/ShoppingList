# <APP_NAME> — правила для агента

Общие правила разработки пользователя действуют. Ниже правила этого проекта.

## Проект в двух словах
Мобильное приложение «<APP_NAME>» — список покупок с планированием по дням. Android сначала, iOS потом.
Expo (React Native) + TypeScript + expo-router + expo-sqlite. Всё офлайн, без сервера. Продукт для массового использования.
Инфраструктура перенесена из «Чекпоинта» (`C:\Projects\Checkpoint`). Подробности: `docs/PROJECT.md`. План: `docs/PLAN.md`.

## Начало сессии (экономия токенов)
1. Прочитай только: этот файл, `docs/STATUS.md`, текущее ТЗ (`docs/tasks/` или `docs/incoming/<версия>/TASK.md`).
2. `docs/PROJECT.md` — по разделам, когда нужно.
3. Не сканируй весь репозиторий. Ищи точечно (Grep/Glob), читай нужные куски.
4. Никогда не читай: `node_modules/`, `package-lock.json`, `.expo/`, `assets/` (бинарники), `android/`.

## Работа
- Делай только то, что в текущем ТЗ. Идеи — одной строкой в `docs/STATUS.md` → «Идеи».
- Неясно или хочется отойти от ТЗ — сначала коротко спроси.
- Пакеты — только через `npx expo install <pkg>` и только после «да» пользователя.
- Без эмулятора. Проверка — на телефоне пользователя (Expo Go на ранних этапах, потом APK).
- `npx expo start` не запускай сам — попроси пользователя.
- Проверки: `npx tsc --noEmit`, `npx expo lint`, `npm test`, `npx expo-doctor`.
- ОС: Windows, PowerShell. ОЗУ 8 ГБ, без видеокарты.

## Эскизы
- Утверждённые эскизы — `docs/sketches/` (список — README там же). Открывай только эскизы текущего ТЗ.
- Нового экрана нет на эскизах — нарисуй блок в `docs/sketches/sketches.html` (стили — как в заготовке) и дождись «ок». Попроси пользователя открыть файл в браузере.
- Утверждённое не перерисовывай.

## Продакшен
Требования — `docs/PROJECT.md` → «Требования продакшена». Готово, если:
1. `tsc`, `lint`, `test` — без ошибок; новая логика покрыта тестами.
2. Тексты — в `src/i18n/` на трёх языках (kk — в `docs/i18n-review.md`), склонения через общую функцию.
3. Миграции БД не теряют данные (тест «старая БД → новая»).
4. Цвета — только через `useTheme()`; контраст по `themes.json`.
5. Нет пакетов с сетью/аналитикой; зоны нажатия ≥ 48 dp, `accessibilityLabel`.
6. Пользователь проверил сценарий на телефоне.

## Код
- Код и имена — на английском, тексты — на русском/казахском/английском через i18n.
- Экраны → `src/logic/` → `src/db/`. Экраны не пишут SQL и не считают правила.
- Маленькие файлы: один экран или компонент — один файл.

## Ответы пользователю
- Пользователь не программист. Отчёт: до 10 строк, простым языком, что сделано и как проверить.
- Не выводи целые файлы и длинные логи.

## Версии и git
- `expo.version` 0.X.Y + `android.versionCode` (+1 на каждую сборку для людей).
- Каждый этап: CHANGELOG, коммит, тег `vX.Y.Z`, push — **только после вопроса пользователю**.

## Конец сессии
Обнови `docs/STATUS.md` (до 20 строк) и `docs/PLAN.md`. Предложи `/clear` перед следующим этапом (или `/compact`, если этап не закончен).
