# Логотип, иконки, живая заставка (опыт «Чекпоинта»)

## Как выбирали логотип (повторить процесс)
1. 8–10 разных направлений (символы предмета, монограмма, персонаж, абстракция) → пользователь выбирает 1–2.
2. Доработка выбранного: 3–6 версий формы и 4 палитры.
3. Проверка «в реальной жизни»: рабочий стол (светлые/тёмные обои, круг и «сквиркл»), тематическая иконка Android 13+, размеры 180/120/72/48/32, заставка, уведомление.
4. Материалы/объём (мягкий 3D, перелив, перламутр, стекло…) — по желанию.
Пользователю нравилось: белый фон иконки, глубокий цвет с лёгким градиентом, мягкий объём; не нравилось — «топорно», шаблонные значки.
Для «Чекпоинта» выбран знак «флаг из кубиков-задач» в ультрамарине (#2433F5 → #1EC8F2). Для нового приложения — **свой знак** (например, корзина/пакет/список из тех же «кубиков-покупок» — обсудить).

## Технические правила иконок
- Сетка 1024×1024; адаптивная иконка Android: видна центральная область 72/108, важное — внутри круга 66/108 (радиус 313 px от центра на 1024).
- Файлы: `icon.png` (непрозрачный, без скруглений и теней — система сделает сама), `adaptive-icon-foreground.png` (прозрачный), фон — цвет, `adaptive-icon-monochrome.png` (белый силуэт для тематических иконок), `notification-icon.png` 96×96 белый силуэт с увеличенными промежутками, `splash-blank.png` (прозрачный — нативная заставка только фоном).
- На тёмном фоне элементы знака не белые (пользователь просил) — светлые тона цвета бренда.
- iPhone позже: основная иконка непрозрачная; тёмная и тонированная версии.

## Живая заставка
- Рисуется кодом (`react-native-svg` + `react-native-reanimated`), **никаких видео/GIF в приложении**. Эталон заставки — `design/splash-animation.html` (открыть в браузере) + `src/logic/splashAnimation.json` (единственный источник таймингов и геометрии).
- Последовательность ShoppingList (~4,1 с): продукты по очереди залетают в пакет, пакет с каждым растёт → приседает и подпрыгивает → при приземлении становится обычного размера → рисуется улыбка (~1 с) → превращается в галочку → название, слоган, «Прототип», «Коснись, чтобы продолжить».
- Нативная заставка — только фон (#FFFFFF в светлом режиме телефона, тёмный — в тёмном), знак рисует живая заставка → без мигания.
- Касание — сразу финальный кадр; «уменьшить движение» — без анимации; показывается только при запуске.
- Цвета знака и заставки — по `applyScope`: «только экраны» → фирменные; «ко всему» → из схемы (`themes.json → schemes[*].mark`).

## Иконка по цветовой схеме (если нужна)
- Android меняет иконку только на заранее вложенную: `activity-alias` на каждую схему + локальный модуль включения alias. WebP, ~150 КБ на 13 вариантов.
- Перед сменой — предупреждение: на части телефонов приложение закроется, ярлык придётся вернуть из меню приложений. Переключать, когда приложение ушло в фон.
