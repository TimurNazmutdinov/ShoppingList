## План сборки 0.7.0 (одна крупная; включает всё из 0.6.2)
1. **Цены:** цена у товара; сумма по списку (всего / куплено / осталось) на карточке и внизу списка; валюта в Настройках — тенге по умолчанию, рубль, своя (символ или код до 4 знаков); цена запоминается вместе с количеством (история).
2. **Поделиться списком** («⋯» → «Поделиться» и в самом списке), форматы:
   - **текст** в мессенджеры (системное «Поделиться»): название, строки «☐ Молоко — 1 л — 450 ₸», итог;
   - **файл приложения** для этого же приложения на другом телефоне (`.json`-формат с версией: список, товары, категории по ключам, цены; без истории); импорт — кнопка «Импорт» (выбор файла) и, по возможности, открытие файла из мессенджера;
   - **текстовый файл** `.txt`;
   - **PDF** (чистый печатный список с галочками и итогом);
   - другие приложения через системное меню «Поделиться».
3. **Резервная копия** — тот же файл приложения, но со всеми списками и настройками; импорт возвращает данные (на новом телефоне, после переустановки).
4. **Первый запуск:** пример списка «Продукты» и короткая подсказка.
5. **Разведка размера APK** (таблица «что весит и что можно убрать»).
**Новые пакеты (нужно «да» пользователя):** `expo-sharing` (отправка файлов), `expo-document-picker` (выбор файла для импорта), `expo-print` (PDF). Файл с телефона на телефон: открытие по нажатию из мессенджера на Android работает не всегда (мессенджеры отдают файл с общим типом) — надёжный путь «Импорт» в приложении.
**Не входит:** общий список для семьи в реальном времени (нужен сервер), варианты сборки dev/public, смена ключа и пакета (после выбора ника).
