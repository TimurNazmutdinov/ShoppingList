# APK: локальная сборка, подпись, релизы, обновления (как в «Чекпоинте» и «Перевале»)

Без EAS и без облака: Android SDK и JDK из Android Studio, сборка из командной строки. Готовый код — в «Чекпоинте» (`scripts/build-apk.ps1`, `plugins/`, `src/logic/updates.ts`).

## Окружение
- `JAVA_HOME` → `C:\Program Files\Android\Android Studio\jbr`; `ANDROID_HOME` → `%LOCALAPPDATA%\Android\Sdk`.
- Android Studio во время сборки закрыть (8 ГБ ОЗУ). Gradle: `-Xmx2048m`, ≤ 2 воркера (через plugin).
- Только `arm64-v8a` и `armeabi-v7a`.
- Ошибка «путь длиннее 260 символов» на Windows — решилась установкой **CMake 3.31.6** (SDK Manager).
- Первая сборка качает зависимости (сотни МБ) и идёт 10–20 мин — предупредить пользователя.

## Нативный проект
- `npx expo prebuild --platform android --clean`; папка `android/` — в `.gitignore`.
- Всё нестандартное — через `app.json` и config plugins в `plugins/` (ручные правки `android/` пропадут).

## Подпись
- Отдельный ключ на каждое приложение. `keytool` из JBR — команду запускает пользователь сам, пароли агент не видит.
- Свойства `<APP>_STORE_FILE`, `<APP>_STORE_PASSWORD`, `<APP>_KEY_ALIAS`, `<APP>_KEY_PASSWORD` — в `%USERPROFILE%\.gradle\gradle.properties`.
- `plugins/withReleaseSigning.js` подключает подпись к release; нет свойств → понятная ошибка.
- 2 резервные копии `.jks` и паролей. Другой ключ = обновление поверх невозможно.

## Сборка — `scripts/build-apk.ps1`
tsc + lint + test → prebuild --clean → `gradlew assembleRelease` → `release\<App>-<version>.apk` (папка в `.gitignore`), размер и SHA-256.

## Релизы
- Публичный репозиторий `<app>-android-apk`: GitHub Release `v<version>` с APK + `latest.json` в `main`:
  `{ "version": "0.6.0", "versionCode": 6, "url": "<страница релиза или прямой APK>", "notes": { "ru": [...], "kk": [...], "en": [...] } }`
- README репозитория: иконка, «прототип для тестирования», как установить (неизвестные источники — один раз), как обновлять.
- Публикация через `gh`, если есть; иначе — инструкция. Перед публикацией — вопрос пользователю.

## Обновления в приложении (сделано в «Чекпоинте» 0.7.2)
- При запуске (раз в сутки) читается `latest.json`; новее → панель «Вышла версия X» с заметками → «Обновить»: скачивание с прогрессом → системный установщик; если нет разрешения на установку — экран с объяснением и кнопкой в настройки.
- Ничего не отправляется; нет сети — молча. Настройки: «Проверять обновления», «Проверить сейчас».
- После обновления лаунчер может показывать старую иконку — помогает перезагрузка телефона (кэш).
