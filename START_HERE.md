# START HERE — новый проект «Список покупок» (на базе наработок «Чекпоинта»)

Этот архив — стартовый пакет для нового чата с Claude (планирование) и для агента Claude Code (разработка).
Прочитай этот файл целиком, остальные — по ссылкам, когда понадобятся.

## 1. Кто пользователь и как он работает
- Тимур, Казахстан. Не программист, делает продукты через вайб-кодинг: Claude (чат) готовит ТЗ, эскизы и пакеты, агент Claude Code на его Windows-ПК пишет код.
- Телефон — Android (Samsung). ПК: Windows, 8 ГБ ОЗУ, без видеокарты; Android Studio установлен (используется только как SDK/JDK, эмулятор не нужен).
- Предпочтения (обязательно):
  - сначала короткий план по этапам, потом код;
  - **эскизы экранов — до любых изменений интерфейса**;
  - объяснения кратко и простым языком: что делаем и зачем;
  - ТЗ для агента: ничего сверх задачи, без больших загрузок, экономия токенов, короткие понятные пункты;
  - картинки агент может показывать прямо у пользователя на компьютере — включать шаг локального просмотра.
- Формат передачи работы агенту — **один архив + один короткий промт** (см. `guides/WORKFLOW.md`). Пользователь иногда даёт задания агенту напрямую — синхронизироваться по его отчётам.
- Продукт **реальный, для широкого использования**, не учебный.

## 2. Что за продукт (черновик — `PRODUCT.md`)
Android-приложение «список покупок»: смахнуть купленное, планировать покупки по дням с отметками в календаре, «напомнить о покупке» (галочка), цветовые схемы, живая заставка, три языка (ru/kk/en). Офлайн, без сервера и аккаунтов. iPhone — позже.

## 3. Что берём из «Чекпоинта» (подробно — `REUSE_FROM_CHECKPOINT.md`)
Репозиторий «Чекпоинта»: `C:\Projects\Checkpoint` (GitHub `TimurNazmutdinov/Checkpoint`, версия 0.7.x). Оттуда **копируем готовый код** инфраструктуры: Expo + TypeScript + expo-router + expo-sqlite, движок тем и 14 цветовых схем, i18n ru/kk/en со склонениями, миграции БД с тестами, CI, ErrorBoundary, локальную сборку подписанного APK, релизы на GitHub с проверкой и установкой обновлений, напоминания (с уроками для Samsung), общий переключатель, панели-формы с правильной работой клавиатуры, живую заставку, пометку «Прототип».
Меняем: название, логотип, `android.package`, ключ подписи (новый!), репозиторий релизов, предметную часть (списки и товары вместо целей и задач).

## 4. С чего начать в новом чате
1. Утвердить **название** и **логотип** (процесс как в «Чекпоинте»: несколько направлений → доработка выбранного → проверка в реальной жизни: рабочий стол, размеры, тематическая иконка, заставка). Варианты названия для старта: «Корзинка», «Купи-ка», «Сумка», «Список» — выбрать с пользователем.
2. Показать эскизы основных экранов (`PRODUCT.md` → «Экраны»).
3. Подготовить архив этапа 0.1 для агента: создать проект, скопировать инфраструктуру из «Чекпоинта», документы проекта (`templates/`).
4. Дальше — этапы по `PRODUCT.md` → «План».
