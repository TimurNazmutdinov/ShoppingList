# Требования продакшена (вставить в docs/PROJECT.md)

**Данные и приватность**
- Никаких серверов, аккаунтов, аналитики, рекламы и SDK, отправляющих данные. Без интернета работает полностью.
- Единственное исключение — проверка обновлений: чтение публичного `latest.json` с GitHub, ничего не отправляется, отключается в настройках.
- Новый пакет с сетевой активностью — только с согласия владельца.
- Данные не терять: миграции только добавляют; каждая — с тестом на sql.js.
- Удаление — только явным действием, с «Отменить» или подтверждением.

**Надёжность**
- Логика (`src/logic/`) покрыта тестами (jest). Новые правила — вместе с тестами. CI на GitHub — зелёный.
- Корневой ErrorBoundary; ошибки БД — понятным текстом.
- Даты — локальные `YYYY-MM-DD`; граничные случаи (конец месяца, год, 29 февраля) — в тестах.

**Объёмы**
- Списки — FlatList/SectionList, запросы с индексами, без загрузки всего сразу.

**Тексты и языки**
- ru / kk / en; все строки в `src/i18n/`; склонения по языку (ru 3 формы, en 2, kk без изменения). kk — на проверку носителем (`docs/i18n-review.md`). Данные пользователя не переводятся.

**Доступность**
- Зоны нажатия ≥ 48 dp, `accessibilityLabel` у иконок и чекбоксов; смахивание продублировано кнопкой/меню (для тех, кому неудобно смахивать).
- Крупный системный шрифт (до 130%) не ломает интерфейс.
- Контраст: текст ≥ 4.5:1, линии и значки ≥ 3:1 — по `themes.json`, автотест.
- «Уменьшить движение» — без анимаций.

**Бережность**
- Без давления: просроченные покупки — нейтрально, без упрёков. Уведомления — не ночью (тихие часы), не чаще раза в день на тему.

**Релизы**
- `expo.version` + `android.versionCode`. Ключ подписи — в `C:\Projects\keys` + 2 резервные копии у владельца; без ключа обновить приложение невозможно.
- Пометка «Прототип» (флаг `IS_PROTOTYPE`) до окончания тестирования; юридические документы — после тестирования.
