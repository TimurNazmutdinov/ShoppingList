1. Убедись, что 0.7.5 закоммичена (если нет — спроси пользователя).

   - `i18n.test.ts` — все ключи есть в ru/kk/en + множественное число (из i18n, plural).
   - `themes.test.ts` — контраст тем и цветовых схем: один табличный тест (из color, schemes).
   - `backup.test.ts` — резервная копия и восстановление.

4. Проверка: `npm test -- --silent`, `npx tsc --noEmit --pretty false` — зелёные.
5. Ответ пользователю: было/стало (файлов, проверок, время прогона). Коммит — после вопроса.
