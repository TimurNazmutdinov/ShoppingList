AAB: `release\SmartShoppingList-0.8.3.aab` (собирает пользователь: `scripts\build-apk.ps1 -Store`). Alpha → «Создать выпуск» → загрузить AAB → заметки ниже → проверка → «Начать внедрение».

## Заметки к выпуску (вставить как есть; каждая ≤ 500 символов)
```
<en-US>
• Intro on first launch: what the app can do
• “⋮” button on an item row: change the category
• “＋ Custom category” is now first in the category row
• Sharing a list: “Whole list” or “Only not bought”
</en-US>
<ru-RU>
• Обучение при первом запуске: что умеет приложение
• Кнопка «⋮» в строке товара: можно сменить категорию
• «＋ Своя категория» теперь первой в ряду категорий
• Отправка списка: «Весь список» или «Только некупленное»
</ru-RU>
<kk>
```
