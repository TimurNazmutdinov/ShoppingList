# Грабли «Чекпоинта» — чтобы не повторять

## Процесс
- Агент иногда сам расширял ТЗ («приоритет и порядок», свои решения в эскизах) и ставил «утверждено» без явного «ок» по каждому эскизу → в ТЗ: эскизы утверждает только пользователь, статус «на согласовании» до явного «ок».
- Номера версий разъезжались (агент выпускал 0.3.1, 0.3.2, 0.7.3 раньше ТЗ из чата) → в каждом пакете шаг «сверка с текущим состоянием»; версию брать от фактически выпущенной.
- Пакет с новым логотипом не был применён (агент работал по старой версии пакета) → один актуальный архив на этап, старые не хранить рядом; в сверке — «какая иконка сейчас в app.json».
- Нумерация эскизов пересекалась → новые эскизы продолжают последний номер в README.
- «Готово» без проверки на телефоне и без зелёного CI → оба пункта — в «Готово, если…».

## Технические
- Windows: путь > 260 символов при сборке → CMake 3.31.6.
- Панели снизу с формой: уходили под системные кнопки и под клавиатуру → учитывать safe area и считать сдвиг клавиатуры по реальной позиции поля на экране; проверять на «Новом элементе» и «Напоминаниях».
- Samsung: напоминания приходили только после открытия приложения → точные будильники + «Состояние напоминаний» + подсказка про «никогда не спящие» (см. `REMINDERS_ANDROID.md`).
- Переключатели плохо видны в тёмной теме → один общий компонент, контраст ≥ 3:1, вкл/выкл различимы положением, 48 dp.
- Градиенты в эскизах: у вертикальной линии нулевая ширина → градиент `objectBoundingBox` не рисуется (использовать `userSpaceOnUse`) — актуально и для SVG в приложении.
- После обновления APK лаунчер может держать старую иконку → перезагрузка телефона.
- Цвета целей хранили сначала как hex → перевели в ключи (`mint`, `blue`…) с миграцией. В новом проекте **сразу ключи**.
- Светлая тема «Белая» должна быть совсем белой (фон #FFFFFF, карточки #F6F6F9 с рамкой) — пожелание пользователя.

## Продуктовые предпочтения пользователя
- Белый или прозрачный фон иконки, тонкие линии, глубокий цвет, лёгкий градиент/объём; без «топорности».
- Флагшток/элементы знака на тёмном фоне — не белые.
- Цветовые схемы: нравятся «девчачьи» спокойные светлые (Пудра, Беж, Ваниль, Персик) и мягкие тёмные светлее «Ночи».
- Отложенные идеи сохранять в `docs/BACKLOG.md`, не делать без команды.
