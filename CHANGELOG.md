# Журнал изменений

## 0.7.0 (versionCode 4) — включает 0.6.2
- Цены: цена позиции у товара, итоги по списку (куплено / осталось / всего) на экране списка и на карточке, валюта в Настройках (₸, ₽ или своя до 4 знаков), цена запоминается вместе с количеством; миграция БД v4.
- Поделиться списком: текстом (мессенджеры), файлом для приложения, .txt, PDF; импорт файла; резервная копия (все списки и история) и восстановление.
- Массовое добавление: «молоко, хлеб, 2 кг сыра» и список, вставленный из мессенджера; многострочное поле ввода.
- Голосовой ввод (кнопка микрофона), при первом использовании сообщение про интернет.
- Блюда (плов, бешбармак, манты, лагман, баурсаки, борщ, оливье, блины): набор продуктов можно изменить перед добавлением.
- Пример списка «Продукты» при первом запуске (если списков нет).
- Новые пакеты: expo-sharing, expo-document-picker, expo-print, expo-speech-recognition.
- build-apk.ps1: package.json сохраняется копией (раньше git checkout терял незакоммиченные пакеты).

## 0.6.2 (versionCode 3)
- Каталог типовых товаров (продукты, хозтовары, бытовая химия) на ru/kk/en: подсказки по первым буквам и категория по названию.
- «Запоминать параметры товаров»: количество и единица запоминаются сразу при добавлении и правке (раньше — только при покупке).
- Количество: кнопка «10» и подпись «Своё число» в поле.
- «Ко всему» = экраны, логотип, заставка и ярлык; иконка рабочего стола по профилям (13 вариантов) с вопросом «Сменить ярлык?» / «Не менять ярлык», как в «Чекпоинте».
- Убрана цифра рядом с названием списка в «Сегодня» и «Календаре».

## 0.6.1 (versionCode 2)
- Живая заставка: продукты залетают в пакет, пакет растёт, прыгает, рисуется галочка.
- «Сегодня» и «Календарь»: товары сгруппированы по спискам.
- Настройки: «Цвета профиля применять — только к экранам / ко всему» (логотип и заставка).
- Девиз заставки «Добавил — Купил — Смахнул» с больших букв.

## 0.6.0 (versionCode 1)
- Первая сборка: списки, товары, смахивание, подсказки из истории, категории, даты, «Сегодня», «Календарь», напоминания, копирование списка, цветовые профили, обновления из приложения.
