# Продукт: «Список покупок» (черновик, название — утвердить)

## Суть
Простой и красивый список покупок для Android. Добавил — купил — смахнул. Можно планировать покупки на конкретные дни, видеть их в календаре и получать напоминание.
Аудитория: взрослые и семьи (не только подростки). Один пользователь, один телефон, офлайн, без аккаунтов и сервера. Языки ru/kk/en. Android первым, iPhone позже.

## Функции (первый выпуск)
1. **Списки**: несколько списков («Продукты», «Хозтовары», «К празднику»), у списка — название и цвет. Сортировка списков вручную.
2. **Товар**: название (обязательно), количество + единица (шт, кг, г, л, уп), заметка, категория, дата покупки (необязательно), «напомнить» (галочка).
3. **Смахивание**: вправо — «куплено» (зачёркнуто, уходит вниз в раздел «Куплено», можно вернуть), влево — «удалить» (с подтверждением «Отменить» внизу 4–5 сек). Нажатие — правка. Работает с одной руки, крупные зоны нажатия.
4. **Быстрое добавление**: строка ввода внизу списка, подсказки из истории («молоко» → «Молоко 1 л»), повторное добавление одним касанием. Голосовой ввод — через клавиатуру телефона.
   - **Только название**: товар можно добавить одним названием, без количества, единицы, категории и даты — всё это необязательно.
   - **Мини-самообучение**: приложение запоминает параметры последней покупки (количество, единица, категория). Купили гречку 0,8 кг — в следующий раз при вводе «греч» предложит «Гречка · 0,8 кг», и товар добавится с этими параметрами. Купили 1 кг — запомнится 1 кг. Всё локально, на телефоне. В Настройках: выключатель «Запоминать параметры товаров» и «Очистить историю покупок». (Таблица `history` уже есть в модели данных.)
5. **Категории**: «Овощи и фрукты», «Молочное», «Хлеб», «Мясо и рыба», «Бакалея», «Напитки», «Бытовая химия», «Другое» + свои; товары в списке группируются по категориям (удобно ходить по магазину). Цвета категорий — из 12 цветов `themes.json → goalColors`.
6. **Планирование по дням**: у товара или у всего списка — дата. Календарь: точки в днях с покупками (цветом списка), под календарём — что купить в выбранный день.
7. **«Сегодня»**: главный экран-подсказка — что купить сегодня + не купленное с прошлых дней (без упрёков).
8. **Напоминания** (галочка «напомнить» у товара или списка): одно уведомление на день в выбранное время: «Сегодня купить: молоко, хлеб и ещё 3». Нажатие — открывает «Сегодня». Настройки — в разделе «Настройки».
9. **Поделиться списком** как текстом (системное «Поделиться» → мессенджер). Без сервера.
10. **Оформление**: 14 цветовых профилей (7 светлых, 7 тёмных) + «Как в системе». Переключатель «Цвета профиля применять: только к экранам / ко всему (логотип, заставка)»: в первом случае логотип и заставка фирменные «Янтарь», во втором — в цвет профиля; по умолчанию «Только к экранам». Живая заставка со своим знаком «пакет с галочкой». Пометка «Прототип» на время тестирования. Название приложения — ShoppingList.
11. **APK вне магазина**: локальная сборка, релизы на GitHub, проверка и установка обновлений из приложения.

## Позже (бэклог)
Повторяющиеся покупки («каждую неделю молоко»), цены и сумма списка, магазины, совместный список с семьёй (нужен сервер — обсуждать отдельно), виджет «Сегодня», резервная копия (экспорт/импорт файла), сканер штрих-кода, iOS.

## Экраны (для эскизов)
1. Заставка (живая, со знаком приложения, «Прототип»).
2. Списки — карточки списков: название, цвет, «осталось купить N», ближайшая дата.
3. Список — товары по категориям, строка быстрого добавления, раздел «Куплено» (свёрнут), смахивание.
4. Товар — панель снизу: название, количество/единица, категория, дата, «напомнить», заметка.
5. Календарь — месяц с отметками, ниже покупки выбранного дня.
6. Сегодня — что купить сегодня и просроченное.
7. Настройки — тема и цвета, язык, напоминания (время, тихие часы, состояние напоминаний), обновления, версия.

## Модель данных (черновик)
```
lists(id, title, color, sort, planned_date NULL, remind INTEGER, created_at, archived_at NULL)
items(id, list_id → lists ON DELETE CASCADE, title, qty REAL NULL, unit TEXT NULL, note NULL,
      category_id NULL, planned_date NULL /*YYYY-MM-DD*/, remind INTEGER DEFAULT 0,
      bought_at NULL, sort, created_at)
categories(id, key NULL /*встроенные*/, title NULL /*свои*/, color, sort)
history(title_norm PRIMARY KEY, title, qty, unit, category_id, used_count, last_used_at)  -- подсказки
settings(key, value)
```
Индексы: items(list_id), items(planned_date), items(bought_at). Миграции — только добавляющие, с тестами.

## План этапов (предложение)
- 0.1 Каркас: копия инфраструктуры «Чекпоинта» (тема/схемы, i18n, БД+миграции+тесты, CI, ErrorBoundary, настройки), новое название/иконка-заглушка.
- 0.2 Списки и товары: создание, правка, смахивание «куплено»/«удалить» с отменой, быстрое добавление, раздел «Куплено».
- 0.3 Категории и подсказки из истории; группировка по категориям.
- 0.4 Планирование по дням: даты, календарь, «Сегодня».
- 0.5 Напоминания (сразу с блоком «Состояние напоминаний» и точными будильниками — уроки Samsung).
- 0.6 APK: логотип, живая заставка, подпись, релизы, обновления (копия из «Чекпоинта»).
- 0.7 Поделиться списком текстом; полировка.
- 0.8 Резервная копия. → тестирование прототипа → юридическое (дисклеймер, соглашение, политика) → пробный период (как в «Перевале») → 1.0.
Каждый этап: эскизы → «ок» → код → проверка на телефоне → релиз.
