# Задание: название приложения по языку телефона

## Цель
Подпись под иконкой зависит от языка телефона:
- ru → «Список покупок»
- kk → «Smart Tizim»
- остальные языки (по умолчанию) → «Shopping List»

Решение пользователя: язык выбирает телефон, не страна. Пользовательские страницы магазина по странам не делаем.

## Шаги
1. **Проверь**, где сейчас задаётся название: `expo.name` в `app.json`, ярлыки (модуль `shoppinglist-alarms`), канал уведомлений, `scripts/build-apk.ps1`. Только Grep, `android/` не читать.
2. **Сделай** название по языку штатным способом Expo для установленной версии SDK: `expo.locales` → `locales/ru.json`, `locales/kk.json`, ключ `android` → `app_name`. Сначала проверь в документации, что это работает для Android в нашей версии SDK.
   - Если не работает — маленький свой config plugin, который пишет `app_name` в `values-ru` и `values-kk`. Новых пакетов не ставить.
   - `expo.name` = «Shopping List» (en, по умолчанию). Не трогай `slug`, `android.package`, `scheme` и ключи хранилища.
3. **Не меняй** заголовки и тексты внутри приложения. Если где-то в интерфейсе выводится название приложения, напиши об этом одной строкой и ничего не правь: изменение интерфейса — только после эскиза и «ок».
4. **Проверки:** `npx tsc --noEmit`, `npx expo lint`, `npm test`. Если логика выбора названия написана кодом (plugin), добавь на неё тест.
5. **Черновик страниц магазина:** `docs/store-listing.md`, три блока (ru, kk, en). В каждом: название (≤ 30 символов), краткое описание (≤ 80), полное описание (≤ 1500, коротко, по `PRODUCT.md`).
   - Названия: ru «Список покупок», kk «Smart Tizim», en «Shopping List».
   - kk: в описании используй слова, которые люди набирают в поиске кириллицей («тізім», «сатып алу тізімі»). Пометь блок «на проверку носителем».
   - Ключевые слова в название не добавлять (правило Google).
6. **Запиши** решение одной строкой в `docs/history.md`.

## Версия и сборка
- Спроси пользователя одной строкой, куда добавить правку: в 0.7.5 (ещё не собрана) или в 0.7.6.
- Gradle не запускать, APK собирает пользователь. Коммит, тег и push — только после вопроса.

## Как проверить (пользователь, на телефоне)
1. Установить APK. Подпись под иконкой — «Список покупок» (телефон на русском).
2. Сменить язык телефона на казахский → «Smart Tizim»; на английский → «Shopping List».
3. Ярлыки на иконке и уведомления работают как раньше.

## Ответ пользователю
До 10 строк: что сделано, куда добавлено, как проверить.
