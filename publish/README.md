# Публикация в Google Play — всё в одной папке

Данные публикации: разработчик **quiteusefulapp** · quiteusefulapp@gmail.com · GitHub `quiteusefulapp`.
Названия: ru «Умный список покупок» · kk «Smart Tizim» · en «Smart Shopping List». Подпись в приложении: «Shopping List».

## Что здесь
- `legal/` — политика конфиденциальности и пользовательское соглашение на ru, kk, en (черновики; kk проверяет носитель). Это не юридическая консультация: перед публикацией желательно показать юристу.
- `store/listing.md` — тексты страницы магазина, список графики.
- `store/data-safety.md` — ответы для формы «Безопасность данных», разрешения, формы Play Console.

## Что выяснили из открытых данных
- Политика нужна **всегда**, даже если данные не собираются; ссылка — в Play Console и внутри приложения. Страница должна быть публичной и открытой, не PDF и не за входом.
- Форму «Безопасность данных» заполняют и при «ничего не собираем»; ответы должны совпадать с политикой.
- Политика должна называть разработчика, контакт, как хранятся и удаляются данные.
- Для РК опора — Закон № 94-V «О персональных данных и их защите»; текст политики написан по общим принципам (хранение на устройстве, без сбора). Актуальность закона и конкретные нормы проверить на adilet.zan.kz.
- `REQUEST_INSTALL_PACKAGES` и самообновление из GitHub в Play-версии нельзя — убрать в публичной сборке.

## Как опубликовать страницы документов (GitHub Pages)
1. На аккаунте `quiteusefulapp` создать публичный репозиторий (например `smart-shopping-list`), положить туда файлы из `legal/`.
2. Settings → Pages → Branch: `main`, `/ (root)`. Адреса вида `https://quiteusefulapp.github.io/smart-shopping-list/legal/privacy-policy.en`.
3. Этот URL вставить в Play Console («Политика конфиденциальности») и в приложение (Настройки → О приложении).

## Порядок работ
1. **Тексты** — готовы здесь (kk проверить).
2. **Приложение** (после эскиза «Настроек» и «ок»): «Валюта и язык»; в «О приложении» — соглашение, политика, разработчик, описание; подпись «Shopping List»; тексты соглашения в окне первого запуска заменить на эти; убрать личные данные.
3. **Названия по языку** (`plugins/withAppNameLocales.js`, `docs/task-app-name.md`) — ru, kk, en как выше; название под значком уточнить (см. вопрос 3 в STATUS).
4. **Поиск по товарам на ru и kk** — проверить и доработать.
5. **Публичная сборка (`public`)**: новый пакет и ключ без личного имени, без самообновления и `REQUEST_INSTALL_PACKAGES`, `IS_PROTOTYPE = false`, AAB. Ключ и пакет — после вашего решения.
6. **Play Console**: создать приложение, страница магазина, Data safety, закрытое тестирование (условия для новых личных аккаунтов проверить на момент выпуска), затем публикация.
