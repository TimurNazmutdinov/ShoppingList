# Google Play: «Безопасность данных» (Data safety) — ответы

Заполнять в Play Console → Политика и программы → Безопасность данных. Ответы должны совпадать с политикой (`legal/privacy-policy.*`). Перед отправкой сверить с актуальной формой Google.

| Вопрос | Ответ |
|---|---|
| Собирает ли или передаёт приложение обязательные типы пользовательских данных? | **Нет** (данные только на устройстве, разработчик их не получает) |
| Данные шифруются при передаче? | Не применимо (передачи нет) |
| Можно ли запросить удаление данных? | Не применимо; данные удаляются удалением приложения / очисткой данных |
| Ссылка на политику конфиденциальности | URL страницы GitHub Pages (см. `README.md`) |
| Реклама | Нет |
| Приложение для детей (Families) | Нет, не для детей |
| Целевая аудитория | 18+ / общая; не детская |
| Доступ к аккаунту, вход | Не требуется (нет аккаунтов) |
| Тип приложения | Приложение (не игра), бесплатное |

## Разрешения (манифест публичной сборки)
- `POST_NOTIFICATIONS`, `SCHEDULE_EXACT_ALARM` — напоминания. Для SCHEDULE_EXACT_ALARM в Play Console нужна декларация «Будильники и напоминания» (основная функция — напоминания о покупках).
- Микрофон — распознавание речи (если плагин добавляет `RECORD_AUDIO`): объяснить как «по нажатию кнопки, служба телефона».
- **Удалить `REQUEST_INSTALL_PACKAGES`** в публичной сборке: Google Play ограничивает это разрешение, а самообновление из GitHub в Play-версии запрещено.
- В публичной сборке выключить проверку обновлений (`UPDATE_URL`) и экран «Нужно обновить».

## Другие формы Play Console
- Контент приложения: реклама — нет; доступ к приложению — без ограничений; целевая аудитория — не дети; новостное/COVID/госприложение — нет; финансовые функции — нет (бюджет только справочный).
- Рейтинг контента (IARC): без насилия, азартных игр, покупок — все возрасты.
- Контакты: email quiteusefulapp@gmail.com (виден в магазине), сайт — страница GitHub Pages.
