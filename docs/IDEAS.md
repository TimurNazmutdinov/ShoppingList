# Идеи для развития (банк идей; сложность: S — день, M — несколько дней, L — отдельный этап)

## Ввод и скорость
| Идея | Зачем | Сложность / пакеты |
|---|---|---|
| **Массовое добавление**: «молоко, хлеб, 2 кг сыра» или вставка списка из мессенджера (разбор по запятым и строкам, количество и единица из текста) | Быстро вносить много; вместе с диктовкой на клавиатуре = «продиктуй весь список» | S, без пакетов |
| **Голосовой ввод** (своя кнопка микрофона) | Руки заняты; микрофон клавиатуры уже работает, своя кнопка нужна ради удобства и разбора списка | M, пакет распознавания + разрешение; казахский зависит от сервиса Google |
| **Штрихкод** | Добавить товар, отсканировав упаковку; название берётся из онлайн-базы (нужен интернет, в Казахстане база неполная). Для офлайн-приложения без аккаунта ценность низкая | M, пакет камеры + база; приоритет низкий. Вариант «свой справочник»: сканируешь один раз, дальше приложение узнаёт товар офлайн |
| **«Часто покупаемое» / «Купить снова»** — кнопки из истории | Одним касанием вернуть привычное | S |
| **«Давно не покупали»**: по периодичности из истории («молоко берёте раз в 5 дней — добавить?») | Умная фишка, офлайн, использует историю | M |
| **Повторяющиеся покупки** («каждую неделю») | Из бэклога продукта | M |
| **Эмодзи у товаров из каталога** (🥛 🍞) | Наглядность, быстрее читать список | S–M |

## Магазин и порядок
| Идея | Зачем | Сложность |
|---|---|---|
| **Режим «В магазине»**: экран не гаснет, крупные строки, купленное уходит вниз | Удобно ходить по магазину | S–M (keep-awake — пакет) |
| **Порядок категорий по отделам магазина**, перетаскивание | Идёшь по магазину без возвратов | M |
| **Закрепить список / архив списков / поиск по спискам / корзина удалённого** | Порядок при большом числе списков | S–M |

## Деньги
| Идея | Зачем | Сложность |
|---|---|---|
| **Цены и итоги** (в плане 0.7.0) | Главное преимущество Listonic по отзывам | M |
| Бюджет списка и предупреждение «превышает» | Контроль расходов | S после цен |
| История цен и сравнение магазинов | «Где дешевле» | M |
| Статистика расходов по месяцам | Видно, куда уходят деньги | M |
| Фото чека (распознавание) | Автозаполнение цен | L, тяжело |

## Совместное использование
| Идея | Зачем | Сложность |
|---|---|---|
| **Общий список для семьи** | Главная функция конкурентов | L, нужен сервер или облако; противоречит «офлайн без аккаунта» — отдельное решение |
| Обмен списком через QR-код (без сервера, для коротких списков) | Передать список рядом сидящему | M |
| Поделиться: текст, файл приложения, .txt, PDF (в плане 0.7.0) | Передать в мессенджер или на другой телефон | M |

## Рынок Казахстана
| Идея | Зачем | Сложность |
|---|---|---|
| **Национальные блюда → ингредиенты в список** (плов, бешбармак, манты, баурсаки…) | Ниша, которой нет у зарубежных приложений; всё офлайн | M, нужен контент на ru/kk |
| Названия товаров казахскими словами в каталоге (есть, расширять, проверка носителем) | Подсказки на родном языке | S |
| Тенге по умолчанию, форматирование сумм «12 500 ₸» | Привычный вид | S (в плане) |

## Напоминания и платформа
| Идея | Зачем | Сложность |
|---|---|---|
| Виджет «Сегодня» на главном экране | Список виден без открытия | M–L, нативный код |
| Напоминание у магазина (геозона) | «Вы рядом с магазином — купить X» | L, геолокация, приватность |
| Автобэкап Android в Google Диск (Auto Backup) | При смене телефона данные вернутся сами; проверить `allowBackup` в сборке | S |
| Ассистент: «Окей, Google, добавь молоко в список» | Голосом без открытия приложения | L |
| iOS, Wear OS | Больше аудитория | L |

## Мелочи интерфейса
Размер шрифта (доступность), своя последовательность единиц («пачка», «бутылка», «банка»), перетаскивание товаров, сортировка внутри категории, оценка приложения и обратная связь, экран «О приложении» с соглашением, онбординг.

## Моя подборка для первого года (по соотношению пользы и сложности)
1. Массовое добавление и вставка списка из мессенджера (S, огромная польза).
2. «Часто покупаемое» и «Давно не покупали».
3. Национальные блюда → ингредиенты (ниша).
4. Режим «В магазине».
5. Автобэкап + экспорт файлом.
6. Затем: голос, виджет, общий список (после решения про сервер).
